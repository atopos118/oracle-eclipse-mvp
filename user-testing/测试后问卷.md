# 测试后问卷

请按1—5分评价：1表示“非常不同意”，5表示“非常同意”。

1. 我愿意经常使用这个产品。
2. 我觉得这个产品不必要地复杂。
3. 我觉得这个产品容易使用。
4. 我需要技术人员帮助才能使用这个产品。
5. 我觉得各部分功能衔接良好。
6. 我觉得产品中有太多不一致。
7. 我认为大多数人可以很快学会使用。
8. 我觉得操作很笨重。
9. 使用时我感到有信心。
10. 在开始使用前，我需要学习很多东西。

SUS计分：奇数题减1，偶数题用5减题目得分，10题合计后乘2.5，范围0—100。

## 内容理解

- 我能分辨科学原理、甲骨记录和学者争议：1 / 2 / 3 / 4 / 5
- 我能判断哪些内容已经审核发布，哪些仍是研究草稿：1 / 2 / 3 / 4 / 5
- 我能找到回答或作品所依据的资料和页码：1 / 2 / 3 / 4 / 5

## 开放问题

- 哪一处最有帮助？为什么？
- 哪一处最难理解或最难操作？
- 对白板/思维导图外观和版面调整有什么建议？
