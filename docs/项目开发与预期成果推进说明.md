# 《甲骨里的日光缺口》项目开发与预期成果推进说明

版本：MVP 0.4  
日期：2026年7月20日

## 当前结论

项目已从单一公众科普原型升级为“公众科普站 + 研究工作台 + 输出工作室 + 审核发布中心 + 百炼适配层 + 可审计证据库”。现有MVP 0.3公众成果保留，并通过稳定快照接入新的研究与发布闭环。

## 已完成

1. 五份MVP 0.4产品与技术基线文档。
2. SQLite证据、知识、作品、审核、提示词和发布模型。
3. PDF、URL、手动文本汇入接口与页面操作面。
4. 页码保留、指纹去重、候选提取和人工审核门。
5. 记录表、观点对照、大众讲解稿和音频导览已审核发布。
6. 来源关系、重解析/删除失效传播和稳定快照发布。
7. 公众端与公众问答统一读取同一快照。
8. 本机研究模式和公众部署模式隔离。
9. `data/`公开白名单完成，旧迁移JSON和变形路径无法绕过稳定快照。
10. 研究台升级为三栏工作流：流程导航、对象列表、详情检查器。
11. 资料汇入后自动处理；支持PDF查看、“页码与原文”查看、改名、审核、取消审核、高级重新处理和批量审核。
12. 知识支持候选编辑、批准、驳回、停用、重新审核和批量批准。
13. 作品支持筛选、完整内容编辑、批准、撤回和批量审核。
14. 公众发布改称“发布版本”，保留版本历史；升级后发布的版本可恢复为新的当前版本。

## 当前数据

- 7篇核心资料已全部导入，其中4篇已审核进入闭环、3篇已完成解析待审核。
- 52172论文拆分为12个PDF页单元；当前仍有40条候选知识等待人工审核。
- 3条记录和2项主题知识已批准。
- 4种首版输出已审核并发布。
- 公众快照含3条记录、5项审核知识、4项审核作品；未审核候选不进入公众端。
- 8项研究工作流与HTTP边界测试通过。
