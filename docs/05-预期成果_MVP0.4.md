# 《甲骨里的日光缺口》预期成果（MVP 0.4）

## 1. 产品成果

| 成果 | 首期交付 | 验收口径 |
|---|---|---|
| 公众科普站 | 图片/视频动态Banner、日食原理、商代认识、记录浏览、公众问答 | 只读取已发布版本；轮播可切换、暂停并支持减少动态效果 |
| 研究工作台 | PDF、URL、手动文本导入、文本质量门、逐页OCR、即时资料问答与公众栏目编排 | 来源确认后可用，回答附页码与确认状态；栏目支持增删、排序、显隐、HTML与简码，修改先草稿和批准 |
| 输出工作室 | 记录表、观点对照、大众讲解稿、正式音频导览、图卡组、讲解幻灯片、视频制作包、研究白板和思维导图 | 仅从已确认资料生成草稿；全部类型可填写受约束的生成要求；媒体作品可导出实际文件；画布尺寸和节点关系可编辑 |
| 审核发布中心 | 作品编辑、删除、批准、撤销发布、失效项和发布版本管理 | 未批准项不能发布；发布版本保持可审计 |
| 百炼适配层 | 公众问答、研究草稿、OCR与正式语音生成 | 上下文边界明确，无依据拒答；音频记录模型和声音 |
| 可审计证据库 | 资料、单元、来源关系、审核和运行记录 | 任一知识/作品可追溯到资料页码 |

## 2. 数据成果

- 7篇核心资料的私有研究副本和内容指纹。
- 逐页文本与解析状态。
- 问答结果形成的AI研究笔记（不作为证据、不参与检索）。
- 经审核的甲骨日食记录、学者观点和争议。
- 页码级公开证据登记。
- 作品、发布知识与AI研究笔记的来源关系图。
- 稳定公众知识快照和发布历史。
- 有序公众栏目、白名单数据简码、安全HTML正文、AI提示审计与只允许当前发布版本读取的Banner媒体。

## 3. 内容成果

首期至少形成：

- 一份审核通过的甲骨日食记录表。
- 一份学者观点与争议对照。
- 一份大众讲解稿。
- 一份经过审核的音频导览文稿、百炼正式中文WAV、网页播放器和下载文件。
- 一组可按卡片生成百炼无文字插图、在线翻页并下载的1080 x 1350 PNG科普图卡。
- 一份可在线播放、可继续编辑的16:9 PPTX讲解幻灯片；结构由百炼生成，支持富文本、Lucide图标、按页生成配图、原生智能图形、真实数据图表、讲者备注、自动换页和转场特效。
- 一套约三分钟的视频制作包，包含脚本、分镜表、SRT字幕和来源清单。
- 一份可拖动编辑、绑定资料页、建立曲线关系并调整版面大小的研究白板，以及一份共用数据模型的思维导图；笔记、证据、资料和作品使用不同视觉语义，审核发布后可在公众端只读查看。

后续可形成资料导读、时间线、证据卡片、学生/研究者讲解和课堂材料；云端专业配音与整段生成视频不列入MVP 0.4成果。

## 4. 技术成果

- 轻量SQLite数据模型和迁移工具。
- PDF/URL/文本解析适配器。
- 百炼逐页OCR、自动质量评分、识别版本与单一人工确认状态机。
- 百炼与本地保底的统一接口。
- 所选资料即时问答与页码级引用。
- 审核门、软删除和失效传播机制。
- 可复现的快照生成器和回归测试。
- 栏目编排状态机、HTML净化、数据简码渲染、双范围栏目生成助手、百炼栏目配图、私有媒体存储和公众媒体发布校验。
- `media_exports.py`与`@oai/artifact-tool`媒体导出层：从审核文稿调用百炼语音生成并缓存WAV，从结构化作品生成PNG、增强可编辑PPTX和视频制作包ZIP；PPTX保留原生文本、图表、图形、备注、转场和播放设置，不读取或公开原始PDF。

## 5. 赛事成果

- 可运行演示系统。
- 项目设计、技术架构、验收清单和运行说明。
- 不超过20页的参赛PPT/PDF。
- 3分钟演示讲解稿和可选视频。
- 用户测试记录与引用准确性测试结果。

## 6. 当前进度

- 公众科普站：MVP 0.3能力已保留，并已改读MVP 0.4稳定快照。
- 核心资料：7/7篇已取得，81页已完成OCR重建并完成来源确认。
- 真实记录：3条已据原刊录入。
- 研究工作台：PDF、URL、手动文本导入、解析、去重、OCR质量门与单一来源确认流程已完成首版。
- 输出工作室：20类作品均可填写受约束的生成要求并保存审计信息；甲骨日食记录表支持在线表格编辑，文字作品支持在线图文编辑及作品图片；音频支持正式WAV，其他媒体支持PNG、PPTX和制作包ZIP导出；研究白板和思维导图支持节点拖动、属性编辑、资料页引用、曲线关系、缩放、自动排列、版面预设和自定义宽高，四类节点具有独立视觉语义；问答结果可选择开放作品类型另存为草稿。综合分块编辑器按独立阶段后续实现。
- 审核发布：作品批准后可显式发布到公众版本，已发布作品支持撤销和编辑后重新审核；当前公众版本不包含尚待新一轮审核的作品，原始资料与旧迁移数据均不公开。
- 自动验证：66项研究工作流、HTTP边界、图文净化、图片与站点媒体发布隔离、生成要求、媒体导出、结构化画布、栏目编排与简码安全和公众问答检索边界测试通过。
- 正式百炼验收：25题首轮均由`qwen-plus`回答，23题自动通过；两项检索问题已修复，完整复测和古文字、天文学、产品、技术人工签署待完成。
- 用户测试：8人测试任务、观察记录、SUS问卷、汇总表与汇总工具已组织完成；真实招募与执行待完成。
- 发布边界：白板和思维导图继续保持私有草稿，外观方案确认前不进入公众站。
