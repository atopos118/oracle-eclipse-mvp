# 《甲骨里的日光缺口》MVP 0.4 技术摘要

完整技术报告见同目录`tech-report.md`。

## 当前系统

产品由公众科普站、研究工作台、输出工作室、审核发布中心、百炼适配层和可审计证据库组成。公众端体验顺序仍是“日食原理—日食类型—商代认识—甲骨记录—互动问答”，但数据只来自审核发布后的稳定快照。

## 当前数据

- 1/7篇核心资料已入库。
- 《合集》11480、21298、33696已据韩宇娇2023年原刊核验。
- 每条记录包含释义、著录、年代边界、学者观点、争议、PDF页和期刊页。
- 残字用“□”；祖庚时期与前1161年对应写为作者论证；救日仪式写为类比推测。
- 原始PDF、逐页文本和私有证据索引不通过网站公开。
- 4类首版输出已生成待审核草稿，未自动进入公众作品库。
- 资料重解析或删除后，下游知识与作品会标记为需要重新审核。

## 主要接口

- `GET /api/health`：服务状态。
- `GET /api/records`：记录与研究线索。
- `GET /api/evidence`：公开页码级证据登记。
- `GET /api/search?q=`：按原文、著录号、观点和争议检索。
- `POST /api/chat`：本地或百炼问答。
- `/api/research/*`：仅本机研究模式开放的导入、解析、审核、生成和发布接口。

## 安全与验证

- 原始PDF、SQLite、解析文本、研究UI和研究API在公众模式下返回403。
- `data/`只公开`published-snapshot.json`，旧迁移JSON不能直接访问。
- 8项研究工作流与HTTP边界测试通过。
