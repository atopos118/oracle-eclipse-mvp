# 《甲骨里的日光缺口》产品设计（MVP 0.4）

版本：0.4  
日期：2026年7月21日  
状态：实施基线

## 1. 产品目标

把现有公众科普站升级为一套“资料进入有门槛、知识发布有审核、作品生成可追溯”的甲骨日食专题系统。首期只服务7篇核心资料及其相关甲骨日食材料，不建设通用NotebookLM替代品。

## 2. 产品结构

1. **公众科普站**：解释日食原理、商代认识和审核通过的甲骨日食记录，提供有来源问答。
2. **研究工作台**：汇入PDF、网页链接和手动文本后自动完成内部解析、页码保留和去重；解析成功即可基于所选资料问答。
3. **输出工作室**：只从已确认资料生成私有草稿；记录表、观点对照、大众讲解稿、正式音频导览，以及图卡组、讲解幻灯片和视频制作包在公开前统一审核。
4. **审核发布中心**：审核作品、维护进入公众快照的发布知识，管理稳定的公众发布版本，处理来源更新造成的失效项。
5. **阿里云百炼服务**：提供有边界的检索增强问答和草稿生成；不可绕过审核直接发布。
6. **可审计证据库**：保存原始资料指纹、文本块、页码、来源关系、模型、系统提示词版本、用户生成要求和审核记录。

## 3. 两类用户体验

### 公众用户

以“先看懂、再读记录、最后提问”为主线。只接触当前公众发布版本，不显示候选知识、内部备注、原始PDF路径或未审核草稿。

### 研究与审核人员

以高密度工作台完成导入、即时问答、生成、确认和发布。解析后立即开放研究操作；界面强调来源、页码、确认状态和发布边界，不把候选知识确认设计为研究前置步骤。

## 4. 核心工作流

```text
资料导入 -> 自动处理、页码保留与去重
  |- 私有研究通道
  |    -> 基于已确认资料问答
  |    -> 生成可编辑作品草稿
  |    -> 明确记录页码来源
  |
  `- 公众发布通道
       -> 确认来源资料
       -> 审核作品与发布知识
       -> 生成稳定公众发布版本
```

模型生成结果只能进入“AI研究笔记”或“作品草稿”，不能写回证据库。来源更新、删除或重新解析后，所有依赖作品自动标记为“来源已更新，需要重新审核”。

公众站全部内容栏目统一进入“站点内容”编排器。研究工作台提供独立三栏编辑：左栏新增、删除、排序和显隐栏目，中栏编辑、源码查看与实时预览，右栏使用提示词助手或自定义提示词调用百炼。每个栏目保留导航名、引言、标题和摘要，其他正文使用安全HTML；研究数据由白名单简码挂载日食互动、甲骨记录、研究成果、公众问答和研究依据。Banner继续支持最多8个图片或视频画面、封面图、启停、排序、停留时长和自动轮播。任何手动修改或AI生成先回到草稿，批准后才进入下一次发布版本，不能直接改动当前公众页面。

提示词助手简化为两个生成范围：“生成完整栏目”一次返回栏目引言、导航名称、标题、摘要、正文HTML、内置组件文案和栏目配图；“仅生成正文HTML”读取现有栏目信息，只替换正文。两种范围都可叠加自定义提示词，并沿用“现象—尺度—机制—互动—证据”的科学表达边界。完整栏目配图由百炼文生图生成并先存入私有站点素材区；配图失败时保留文字草稿并提示重试。系统不复制具体脚本和画面，不把纪录片表达作为学术证据。公众问答和研究问答共用同一组织原则解释科学问题，但仍只能引用各自获准使用的事实与来源。

“解析单元”是内部数据结构，不作为用户必须操作的独立步骤。研究台统一显示为“页码与原文”；自动处理失败时提供重试，主动重新处理放在高级操作中。研究台不再提供“待确认知识”作为独立导航或前置步骤。历史候选知识表保留用于旧数据和旧快照兼容；新的资料确认后直接作为证据进入私有研究通道，只有准备公开时才进入发布审核。

来源确认是私有问答和草稿生成的前置条件，文本质量门仍是更早的前置条件。正常文本层可在资料库查看但需点击一次“确认资料”；乱码PDF必须先逐页OCR，再点击一次“确认OCR文本”，该动作同时完成来源确认。未经确认的资料不参与问答与输出。PDF详情以左右分栏同步展示原页和页码原文，点击页码会跳转PDF到对应页。问答结果可以保存为“AI研究笔记”或选择任意作品类型另存为作品草稿。AI研究笔记保留问题、回答、引用和模型来源，但明确不作为证据、不参与模型检索、不进入公众快照。

## 5. 首版输出工作室

优先实现：

1. 甲骨日食记录表。
2. 学者观点与争议对照。
3. 大众讲解稿。
4. 音频导览文稿、百炼正式中文WAV、研究台/公众端网页播放器与下载文件。

在四类核心模板之上，MVP 0.4增加三类可审计媒体作品：

1. **甲骨日食科普图卡组**：生成3至6张结构化图卡草稿，可预览单张1080 x 1350 PNG并下载PNG压缩包。
2. **甲骨日食讲解幻灯片**：生成5至9页讲解结构，可下载16:9 PPTX继续编辑。
3. **甲骨日食视频制作包**：生成约三分钟的分镜、旁白、屏幕文字、字幕和来源清单，可下载ZIP进入剪辑流程。

音频由审核文稿通过百炼语音模型按需合成为中文WAV，并记录语音模型与声音；图卡结构由百炼生成，插图由用户按卡片显式调用百炼文生图，模型不得生成文字或伪造甲骨原片，标题、正文和来源由本地排版；幻灯片由百炼生成结构并本地导出可编辑PPTX，不让模型直接生成不可编辑的整页截图；图卡和幻灯片在研究台与公众站提供单页翻页阅读。视频类只交付可编辑制作素材，不自动生成整段视频。四类媒体结果与其他模型输出相同，先进入作品草稿，保留模型、系统提示词版本、用户生成要求、资料版本和页码关系，批准后才可发布，并且不得写回证据库。

作品类型采用开放目录：四类核心模板、三类媒体模板和研究白板/思维导图均提供快捷入口，另支持研究问答、文献摘要、资料导读、断代时间线、证据卡片、学生版和研究者版讲解、科普图卡、课堂材料、短视频脚本与字幕等，共20种类型。全部类型共用一个可选“生成要求”字段，用于指定受众、语气、篇幅、重点顺序和表现形式。

作品采用“多编辑器、统一工作区”，不让自由白板代替结构化内容编辑。甲骨日食记录表使用可增删行列的在线表格；包含正文的文字作品使用图文编辑器，支持标题、粗体、斜体、列表、引用、链接和作品插图；其他结构化作品继续使用高级JSON。图文正文同时保存净化后的HTML和由服务端同步生成的纯文本，前者用于排版发布，后者用于检索与问答。编辑器图片采用内容哈希保存为作品派生资源，不进入证据库，只有当前发布版本实际引用的图片才允许公众读取。

独立白板与思维导图作品已经接入统一工作区。白板用于自由整理、批注和证据关系，思维导图以中心主题组织结构化分支；两者共用可审计节点/关系模型，支持节点拖动、类型与颜色编辑、资料页绑定、连线、缩放和自动排列。节点只引用资料页、知识条目或作品，不复制或改写证据；保存后仍按草稿、批准、发布和失效复核流转，公众端只读展示已发布版本。下一阶段再以分块方式组合文章、表格、图卡、音频和白板，形成综合编辑器。自由白板不承担正式记录表和文章正文的权威编辑职责。

用户生成要求最多500字，作为不可信的表达偏好独立传入模型。它不得改变释文、著录号、年代、学者观点、争议、来源页码、审核状态或发布状态，也不能让未经确认资料进入问答与输出。

## 6. 产品原则

- 原始资料私有，公众页面不提供PDF下载。
- 公众论文标题链接项目内部来源详情；原始取得地址和私有PDF只在研究台保留。
- 未审核内容不可进入公众问答。
- 已确认资料可以进入私有资料问答，回答必须附页码和确认状态。
- 文本质量异常的资料不得进入问答或作品生成，必须先完成OCR重建。
- 任何结论必须能追溯到资料和页码。
- 任何模型生成必须记录模型、系统提示词版本、用户生成要求、输入资料和生成时间。
- 发布是显式动作，不因生成完成自动发生。
- “批准”表示内容通过内部审核，“发布”表示把一组已批准内容作为完整版本更新到公众端，两者必须分离。
- 每次发布冻结当时的知识、作品与来源边界；编辑或撤回先在研究台形成下一版本，不能让公众端处于半完成状态。
- 每次发布同时冻结站点内容；Banner草稿媒体保存在私有素材区，公众接口只读取当前发布版本实际引用的媒体编号。
- 升级后产生的历史发布版本可恢复，但恢复会生成新版本，不覆盖或删除历史记录。
- 资料变化必须向下游传播失效状态。
- 对缺少依据的问题明确拒答，不用模型常识补齐甲骨材料。

## 7. MVP 0.4成功标准

- 7篇核心资料能够完成“导入—解析—审核—生成—发布”闭环。
- 公众端只读取一个稳定发布版本。
- 4种核心输出与3种媒体扩展均可生成草稿并记录来源关系；音频可导出WAV，其他媒体作品可导出PNG、PPTX或制作包ZIP。
- 删除或重解析资料后，下游内容自动失效。
- 引用能够定位到PDF页或网页/手动文本单元。
- 7篇核心资料共81页已经完成OCR重建和来源确认；自动验证保持33项通过。
