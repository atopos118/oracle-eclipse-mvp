# 《甲骨里的日光缺口》产品范围（MVP 0.4）

## 1. 本期范围

### 资料输入

- PDF文件：汇入后自动处理，保留文件指纹、总页数、逐页文本和处理状态。
- 网页链接：保存规范化URL、抓取时间、正文文本和内容指纹。
- 手动文本：保存标题、正文、录入人说明和内容指纹。

### 资料处理

- SHA-256去重。
- 逐页或逐单元文本存储。
- PDF文本质量检测、逐页PNG渲染、百炼视觉OCR、识别版本和一次性来源确认。
- 来源更新、删除、重解析后的依赖失效。

### 知识与作品

- 私有资料问答：仅从已确认资料检索相关片段并返回页码与确认状态；未经确认资料不参与问答与输出。
- 发布知识：释文、著录号、年代、观点、争议、来源页码和审核状态；不设置新的“待确认知识”前置模块。
- AI研究笔记：问答结果可保存为研究记录，但不作为证据、不参与检索、不进入公众快照。
- 作品草稿：记录表、观点对照、大众讲解稿、音频导览、研究白板、思维导图，以及开放目录中的其他作品类型；全部类型支持最多500字的可选生成要求。
- 结构化画布：白板与思维导图共用节点、关系和视口模型，支持拖动、编辑、来源页绑定、连线、缩放和自动排列；公众端只读展示已发布画布。
- 媒体作品：音频导览通过百炼语音模型合成，可在研究台播放并下载中文WAV；科普图卡组由百炼生成结构，插图按卡片显式调用百炼文生图后合成1080 x 1350 PNG与PNG压缩包，研究台与公众站支持单页翻页；讲解幻灯片由百炼生成结构并导出可编辑16:9 PPTX，研究台与公众站支持单页翻页；视频制作包可导出包含脚本、分镜表、SRT字幕和来源清单的ZIP。
- 作品审核：仅从已确认资料生成草稿；支持编辑、删除、批准、撤销发布、重新生成和失效后重审。
- 公众快照：只包含已批准知识、已批准作品摘要和公开来源元数据。
- 站点栏目：公众站全部栏目可新增、删除、排序和显示/隐藏；导航名、引言、标题、摘要采用结构化字段，正文提供可视HTML与源码编辑。内置简码只读取发布版本中的日食互动、甲骨记录、研究成果、公众问答和研究依据，不执行脚本或任意接口。栏目支持手动编辑、实时预览、提示词助手、批准和随版本发布。Banner继续支持图片、MP4/WebM视频和动态轮播。

### 模型能力

- 百炼兼容接口适配。
- 仅从用户选定的已解析资料和已批准知识构造私有研究上下文。
- 记录模型名、系统提示词版本、用户生成要求和输入依赖。
- 站点内容提示词助手只提供“生成完整栏目”和“仅生成正文HTML”两个范围；两者都可叠加自定义提示词。完整栏目包含结构化字段、正文、内置组件文案和私有栏目配图，正文模式不修改其他字段。两者都沿用“现象—尺度—机制—互动—证据”框架，只改变页面表达，不允许补写甲骨事实字段。
- 无密钥时提供确定性的本地草稿生成，保证闭环可测试。

## 2. 明确不在本期范围

- 通用个人知识库或跨领域NotebookLM替代品。
- 多租户、组织级权限和复杂账号体系。
- 原始PDF公开预览或下载。
- DOCX、Markdown、独立扫描图片批量导入、音视频转录的正式实现；本期仅实现已入库PDF的逐页OCR。
- 自动学术定论、自动断代或自动接受模型生成内容。
- 将模型生成的AI研究笔记重新作为证据或检索资料。
- 自动发布、自动将模型输出作为新证据。
- 整段视频渲染、文生视频、云端专业配音，以及冒充甲骨原片的自由图像生成。
- 直接搬运、下载或复刻受版权保护的纪录片脚本与画面；本期只抽象其科学叙事和交互设计方法。

## 3. 后续扩展接口

输入类型预留`docx`、`markdown`、`image_ocr`、`audio_transcript`和`video_transcript`。作品目录已提供20种类型：4种核心快捷模板、3种媒体快捷模板、研究白板、思维导图，以及研究问答、文献摘要、资料导读、断代时间线、证据卡片、学生讲解、研究者简报、科普图卡、课堂材料、短视频脚本和字幕；后续可继续扩充目录。

## 4. 安全边界

- 私有研究API默认只允许本机访问。
- `source-materials/`、私有数据库、导入文件和解析文本禁止静态访问。
- URL导入拒绝本机地址、私有网段和非HTTP(S)协议。
- 上传文件限制类型和大小，文件名经过清理。
- 公众API不返回内部路径、全文块、提示词正文或审核备注。
- 私有问答只传输用户选择资料中检索到的必要文本片段，不传输原始PDF或整个数据库。
- 媒体导出只包含作品内容和必要来源清单，不打包原始PDF、逐页全文或私有路径；公众音频接口只接受当前发布版本中的音频作品编号。
