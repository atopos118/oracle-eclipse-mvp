# 日食纪录片内容转化规范

版本：1.0  
日期：2026年7月23日  
适用范围：公众站科普内容、站点内容提示词助手、公众问答与研究问答的科学表达

## 1. 目标

从高品质日食视频和纪录片中提炼沉浸感、科学解释、形象化表达和互动设计方法，同时保持甲骨研究的来源边界。纪录片属于创作参考层，不属于甲骨证据库；作品中的事实必须由已审核资料或权威科学资料支持。

## 2. 参考来源准入

每个视频来源登记片名、出品机构、公开链接、观看日期、适用片段、时间码、授权或引用条件和记录人。优先级依次为官方科学机构、天文台或博物馆、公共教育机构、高质量科学纪录片。来源至少满足以下条件：

1. 科学表述可与权威资料交叉核对。
2. 日月地关系、影锥、观测位置和日食类型没有明显误导。
3. 镜头或动画能说明因果，而非只制造氛围。
4. 有明确的公开访问与使用边界。
5. 能提供字幕、文字说明或无障碍替代信息。

未明确授权的画面、音乐和脚本不下载、不嵌入、不改写复刻。可以记录“从近景观察切换到空间尺度”等抽象方法，但不保存大段逐字稿。

## 3. 五段转化方法

### 现象

记录观众能够感知的变化，例如日面缺口、天光变化、树影形态和周围环境反应。不得虚构具体地点、人物或观测体验。

### 尺度

标记镜头如何在观察者、地表路径、月球影锥和日月地空间关系之间切换。比例示意必须明确是解释模型，不能让用户误以为画面按真实比例绘制。

### 机制

提取遮挡、视位置、影锥和轨道几何的因果链。每个类比同时记录适用范围和可能误解。

### 互动

把被动观看转成一个明确动作：预测后揭晓、拖动日月地对齐、拖动时间进程、切换三类日食或逐层展开证据。操作必须改变用户能观察到的结果，并立即解释原因。

### 证据

科学原理回到权威科学资料；甲骨记录回到已审核论文、页码和争议。页面明确区分已核验、学者观点、存在争议和尚不清楚。

## 4. 栏目映射

| 内容区 | 主要任务 | 推荐互动 | 禁止做法 |
| --- | --- | --- | --- |
| Banner | 建立一个真实可观察的日食瞬间和核心悬念 | 暂停轮播、进入科学解释 | 堆叠多个口号、使用无来源影视片段 |
| 科学原理 | 解释日月地关系、影锥和三类日食 | 预测揭晓、拖动对齐、类型对比、时间进程 | 只播放动画而不解释因果 |
| 甲骨时代 | 从现代现象过渡到先人的记录行为 | 现代观察与卜辞证据并置 | 神秘化复原、把贞问直接判为固定凶吉 |
| 日食记录 | 展示释义、年代、观点、争议和来源 | 证据逐层展开 | 把争议结论写成确定事实 |

## 5. AI 内置提示词规则

系统先读取当前栏目简报和选定互动模式，再读取纪录片观察笔记，最后读取已审核知识。优先级固定为：证据边界高于用户提示，审核知识高于观察笔记，当前字段结构高于模型自由发挥。

模型只能把观察笔记用于以下内容：

- 开场观察顺序。
- 空间尺度切换。
- 因果可视化步骤。
- 互动动作和反馈节奏。
- 旁白的清晰度、句长和停顿。

模型不得从观察笔记补充甲骨原文、著录号、断代、日食对应日期、学者观点或争议结论。生成结果只进入站点内容草稿，记录模型、提示版本和生成要求，人工批准后才能随新版本发布。

## 6. 单片观察记录模板

```text
科学因果：
可转化互动：
无障碍替代：
可能误导或不适用之处：
需要另行核验的事实：
```

## 7. 发布验收

1. 每个公开科学结论可追溯到审核知识或权威科学资料。
2. 每个互动只有一个清楚的认知目标，并有即时反馈。
3. 影视化表达不冒充甲骨原片、历史现场或学者定论。
4. 视频静音时仍可理解；提供字幕、替代文字和减少动态效果回退。
5. 生成内容不含具体纪录片脚本复述、未授权画面或来源不明的事实。
6. 站点内容保持草稿、批准、发布三步，不自动覆盖当前公众版本。
