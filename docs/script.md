# 《甲骨里的日光缺口》讲解稿（3分钟版）

**场合：** 答辩现场 / 演示视频 / 评委汇报  
**版本：** MVP 0.4

## 开场（0:00-0:25）

大家好，我们的项目叫《甲骨里的日光缺口》。我们希望让普通公众先看懂日食，再读懂三千多年前的人怎样记录和理解这种天象。AI负责降低阅读门槛，但不能替学者补写残字、断代或结论。

## 看懂日食（0:25-0:55）

日食发生时，月球来到太阳和地球之间，月影扫过地球。这里可以移动月球轨道，看到为什么大多数朔月不会发生日食；下方还可以切换日全食、日环食和日偏食。

## 回到商代（0:55-1:20）

论文把日月食讨论为严重异象或不吉之象。人们会向祖先报告、询问祭牲，并担心它是否给商王带来忧祸。但卜辞提出问题，不等于已经给出固定的凶吉答案。

## 打开记录（1:20-1:55）

点击记录可以同时展开多个详情。首篇论文已经支持三条具体材料：《合集》11480、21298和33696。每条都显示白话释义、年代、著录、论文页码、学者观点和争议。看不清的残字用方框保留；前1161年和祖庚时期明确标为韩宇娇的论证，不写成定论。

## 研究到发布（1:55-2:25）

公众页面背后还有一套不公开的资料研究台。论文导入后先按页解析和去重，再提取候选知识，经过人工审核才能发布。我们还可以从选定资料生成记录表、观点对照、大众讲解稿和音频导览。生成结果永远先是草稿，并记录资料页码、模型和提示词版本，不能自动回流成证据。

## 互动问答（2:25-2:45）

用户可以输入一句卜辞或著录号，也可以问“当时的人认为日食是凶是吉”或“能不能列出记录表”。回答会附PDF页和期刊页。没有百炼密钥时使用本地知识库，配置密钥后调用Qwen；调用失败仍可回退。

## 成果与下一步（2:45-3:00）

当前已经完成公众科普、私有研究、输出草稿、审核发布和可审计来源关系的首篇论文闭环。下一步是取得其余六篇论文，完成专家复核、正式百炼回归和用户测试，再部署公众模式并制作参赛材料。谢谢大家。
