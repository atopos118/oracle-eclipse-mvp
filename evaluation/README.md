# 百炼正式验收

本目录用于验证公众问答是否在已发布知识边界内稳定工作。验收结果只保存在
`evaluation/reports/`，不得导入资料库、证据库、发布知识库或作品库。

## 验收前提

1. 研究服务已从用户环境变量读取 `DASHSCOPE_API_KEY`，顶部模型状态显示“百炼”。
2. 公众站读取当前发布版本，7篇资料均已完成OCR确认和来源确认。
3. 测试期间不修改发布内容；如发布内容发生变化，应重新运行全部问题。

## 执行

```powershell
python evaluation/run_bailian_evaluation.py --base-url http://127.0.0.1:8000
```

默认要求每题实际使用百炼。若接口降级到本地规则，报告仍会生成，但进程返回失败，
不能作为正式通过。仅排查题目和报告格式时可使用：

```powershell
python evaluation/run_bailian_evaluation.py --allow-fallback
```

生成结果：

- `reports/latest.json`：机器可读明细。
- `reports/latest.md`：人工复核表。
- 带时间戳的同内容归档：用于对比不同模型、提示词和发布版本。

## 通过条件

- 模型模式：全部题目为 `qwen`，无本地降级警告。
- 自动检查：全部题目满足预期关键词、引用数量、引用结构、拒答和禁用表达规则。
- 引用复核：涉及甲骨记录、断代、观点和争议的问题，人工确认资料与页码对应。
- 边界复核：不得补写残字、伪造著录号、把争议说成定论，或把贞问直接判作固定吉凶。
- 性能记录：保留每题延迟；超时、失败和重试必须如实记录，不删除失败样本。

## 人工复核角色

- 古文字学复核：释文、著录、分期、作者观点与争议边界。
- 天文学复核：日食原理、候选日食日期和天文对应表达。
- 产品复核：公众可读性、拒答是否清楚、引用入口是否可理解。
- 技术复核：模型、提示词版本、发布版本、错误与延迟记录是否完整。

四类复核完成后，在 `latest.md` 的人工结论中签名或登记姓名与日期，才可将第5项标记为完成。
