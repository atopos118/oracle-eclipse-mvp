# 本地研究资料目录

本目录用于保存经登录授权取得的核心原刊，以及逐页提取的研究文本。

- `pdfs/`：原始 PDF，仅供项目研究与人工核验，不在网站中公开。
- `extracted/`：按页提取的全文，供建立页码级证据索引使用。
- `ocr-pages/`：本机渲染的私有逐页PNG，供百炼视觉OCR使用，不公开。
- `research-pre-ocr-20260721.db`：OCR质量门上线前的证据库备份。
- `manifest.json`：文件来源、SHA-256、页数和提取状态。

`server.py` 会拒绝所有 `/source-materials` 请求；原刊与全文提取物也已加入 `.gitignore`。

2026年7月21日确认7篇PDF的内嵌文本层均存在字体编码乱码。旧解析版本保留用于审计，但已停止参与问答、知识提取和发布；新文本必须经过逐页OCR、质量检测和人工复核。
